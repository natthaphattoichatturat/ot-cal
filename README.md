# ระบบคำนวณชั่วโมง OT พนักงานโรงงาน

ระบบ Web Application สำหรับคำนวณและจัดการชั่วโมง OT (Overtime) ของพนักงานโรงงาน พัฒนาด้วย Next.js 14 และ Supabase PostgreSQL

## ฟีเจอร์หลัก

### 1. นำเข้าข้อมูลการสแกนใบหน้า
- รองรับการนำเข้าไฟล์ .txt จากเครื่องสแกนใบหน้า
- ตรวจสอบข้อมูลซ้ำอัตโนมัติ
- คำนวณ OT ทันทีหลังนำเข้าข้อมูล

### 2. คำนวณ OT อัตโนมัติ
- รองรับ 2 กะการทำงาน:
  - **กะที่ 1**: 08:00 - 17:00 (OT ก่อนเวลา: 06:00 - 08:00, OT หลังเวลา: 17:30 เป็นต้นไป)
  - **กะที่ 2**: 20:00 - 05:00 (OT ก่อนเวลา: 17:30 - 20:00, OT หลังเวลา: 05:30 เป็นต้นไป)
- คำนวณ OT ทุกๆ 30 นาที (0.5 ชั่วโมง)
- รองรับการทำงานข้ามวัน
- จัดการกรณีพิเศษ:
  - ทำงานข้ามตี 3 = สามารถเข้างานเวลา 13:00 วันถัดไป
  - ทำงานในช่วง 02:00-03:00 = OT สูงสุด 8 ชั่วโมง
  - ตรวจจับช่วงพักเที่ยง (00:00-01:00) สำหรับกะ 2

### 3. คำนวณ OT พิเศษ
- วันอาทิตย์และวันหยุดพิเศษ:
  - 8 ชั่วโมงแรก × 2
  - หลังจาก 8 ชั่วโมง × 3
- วันธรรมดา: × 1.5

### 4. แสดงผลแบบ Excel-Friendly
- UI ออกแบบให้คล้าย Excel
- แสดงข้อมูล 2 งวดบัญชี:
  - งวดที่ 1: วันที่ 26 (เดือนก่อน) - 10 (เดือนปัจจุบัน)
  - งวดที่ 2: วันที่ 11 - 25 (เดือนปัจจุบัน)
- ระบายสีตามวัน (จันทร์-อาทิตย์)
- แสดงชั่วโมง OT แต่ละวันในตาราง

### 5. บันทึกการลางาน
- บันทึกข้อมูลการลาพนักงาน
- ประเภทการลา: ลากิจ, ลาป่วย, ลาพักร้อน, อื่นๆ
- ค้นหาประวัติการลาตามพนักงานและช่วงวันที่

## การใช้งาน

### 1. นำเข้าข้อมูลการสแกน

1. เตรียมไฟล์ .txt ที่มีรูปแบบ:
```
01	11-10-2025	07:54:00	'20056402	1
04	11-10-2025	17:02:16	'20056402	2
```

รูปแบบ: `machine_id  dd-mm-yyyy  HH:MM:SS  'employee_id  scan_type`
- machine_id: รหัสเครื่องสแกน
- วันที่: dd-mm-yyyy
- เวลา: HH:MM:SS
- employee_id: รหัสพนักงาน (มี ' นำหน้า)
- scan_type: 1 = เข้างาน, 2 = ออกงาน

2. คลิก "เลือกไฟล์" บนหน้าหลัก
3. คลิก "นำเข้าข้อมูล"
4. ระบบจะประมวลผลและแสดงผลในตาราง

### 2. ดูข้อมูล OT

- เลือกเดือนและปีที่ต้องการ
- ระบบจะแสดง 2 ตาราง (2 งวดบัญชี)
- แต่ละ cell แสดงชั่วโมง OT ของวันนั้นๆ
- คอลัมน์สุดท้ายแสดงรวม OT ทั้งงวด

### 3. บันทึกการลา

1. คลิก "บันทึกการลา" บนหน้าหลัก
2. เลือกพนักงาน, วันที่ลา, ประเภทการลา
3. ระบุเหตุผล (ถ้ามี)
4. คลิก "บันทึกการลา"

## กฎการคำนวณ OT

### กะที่ 1 (08:00-17:00)

**OT เช้า (06:00-08:00)**
- เข้างานก่อน 08:00 = ได้ OT
- สูงสุด 2 ชั่วโมง
- นับทุก 30 นาที

**OT ค่ำ (17:30 เป็นต้นไป)**
- เลิกงานหลัง 17:30 = ได้ OT
- นับทุก 30 นาที
- กรณีทำข้ามวัน:
  - ออกก่อน 02:00 = OT ปกติ
  - ออก 02:00-03:00 = OT สูงสุด 8 ชม.
  - ออกหลัง 03:00 = OT ไม่จำกัด + ยกเว้นมาสายวันถัดไป

### กะที่ 2 (20:00-05:00)

**OT เย็น (17:30-20:00)**
- เข้างานก่อน 20:00 = ได้ OT
- นับทุก 30 นาที

**OT เช้า (05:30 เป็นต้นไป)**
- เลิกงานหลัง 05:30 = ได้ OT
- นับทุก 30 นาที

**การจัดการช่วงพัก**
- ระบบตรวจจับการสแกนเข้าซ้ำในช่วง 00:00-01:00
- นับเป็นช่วงพัก ไม่นับเป็น work session ใหม่

### อัตราคูณ OT

**วันธรรมดา (จันทร์-เสาร์)**
- OT ทั้งหมด × 1.5

**วันอาทิตย์ / วันหยุดพิเศษ**
- 8 ชั่วโมงแรก × 2
- เกิน 8 ชั่วโมง × 3

## Database Schema

### employees
พนักงาน

### attendance_scans
บันทึกการสแกนใบหน้าดิบจากเครื่อง

### daily_attendance
สรุปการทำงานและ OT รายวัน (คำนวณแล้ว)

### special_holidays
วันหยุดพิเศษ (วันหยุดราชการ, วันหยุดบริษัท)

### leave_records
บันทึกการลางาน
